# 第一章

正文从这里开始。把这个文件改成你的第一章，
新章节就在 `chapters/` 目录下加新的 `.md` 文件，
然后在 `.vitepress/config.mts` 的 `sidebar` 里登记一行。

## 排版速查

写作时常用的几种 Markdown 语法：

**加粗**、*斜体*、~~删除线~~、`行内代码`。

> 引用一段别人的话，记得注明出处。

分隔小节用二级 / 三级标题（`##` / `###`），右侧「本页目录」会自动生成。

::: tip 提示
VitePress 还支持这种提示框，类型有 `tip` / `info` / `warning` / `danger`。
:::
